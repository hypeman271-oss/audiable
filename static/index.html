      Settings

      App

      Mode Simple: just listen — pared-down controls. Standard: bookmarks, sleep, A↔B loop, library tools, annotations & voice notes. Author: writing-craft tools (word count, long-sentence + filler-word callouts, character voices).

      Theme Auto follows your device setting. Light mode uses a warm cream palette tuned for outdoor or daytime reading.

      Sync library across devices Stores your library on the Narrative server so you can edit on your desktop and listen on your phone. New saves push as you go; pulls happen when you open the library. Off by default — flip on per device.

      Start-a-new-clip helper The four-tile helper above the textarea (Paste URL / Upload file / Browse GitHub / Try sample text). Hide it once you know the moves; bring it back any time.
      Library pane (desktop) The Library list pinned to the left edge on screens 1280px and wider. Hide for a wider center column when you don't need quick clip-switching. Re-open from the 📚 pill at the left edge, this toggle, or ⌘K → "Show library pane".
      Notes pane (desktop) The right-side pane that holds Voice + the "This clip" summary (flags, bookmarks, notes). Hide for more reading room. Re-open from the 📝 pill at the right edge, this toggle, or ⌘K → "Show notes pane".

      Player

      Skip interval How far the ↶ and ↷ chips jump. Default is 5 seconds. Smaller for re-listening tricky sentences; larger for skipping past sections you already heard.
      Pause after paragraph Auto-pause for a beat at the end of each paragraph so you can process what you heard — and tap to flag it in annotate mode. Resumes automatically; press play to skip the wait.
      Keep screen on while playing Stops the phone or laptop from sleeping while audio is playing — useful if you're reading along with the narrator. Costs a little battery; off by default. Releases automatically when you pause or the clip ends.

      Book view

      Text size How large the body text reads when the book view is open. Larger sizes mean more pages but less squinting. Re-paginates instantly when you change it.
      Typography Paperback: classic serif, single column. Magazine: sans-serif, two columns on desktop. Manuscript: monospace, looser lines, left-aligned — reads like a typewritten draft.

        Which scopes does Narrative actually use?

        The Create one → link pre-ticks repo because that's what most writers need (private drafts). Here's what each scope grants and what Narrative does with it.

        Scope Narrative uses it for Recommended?
        repo Reading files from private repos via Import → GitHub + the per-clip GitHub URL fetch. Yes if you import private drafts. Skip if you only read public books — use public_repo.
        public_repo Reading files from public repos. Subset of repo. Yes if your manuscripts are public (or you only read other people's public repos). Strictly safer than repo.
        read:user Showing "Signed in as @yourhandle" in this Settings dialog (cosmetic only). Optional. Without it the section reads "Token saved" instead of your handle — still works.
        everything else Not touched. Narrative never calls write, admin, gist (mutate), pages, workflow, or organization scopes. Skip. If GitHub's PAT page has them ticked, untick them.

        Fine-grained PATs work too — pick the exact repos you want Narrative to see, then grant Contents → Read-only. Sync GitHub + re-narrate need Metadata → Read-only too.

          Characters

          Assign a voice (and speaker, for multi-speaker models like LibriTTS) to each character. When you Generate, sentences containing a character's name near a quote will be narrated in that character's voice. Other text uses the main voice picker.

          Browse voices

          💡 Tap the ☆ on any voice to star it. Starred voices float to the top of the main voice picker as a ★ Favorites group.
          ⚖️ Publishing what you generate? Tap Commercial only to narrow the catalog to voices whose license permits selling the audio (with attribution). The Voice provenance block on each clip's ✎ Edit dialog has the exact credit line to copy.
